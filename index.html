Capstone

mmWave Radar 3D Imaging System

This capstone project is a proof-of-concept security screening platform that fuses four independent sensing modalities: millimeter-wave synthetic aperture radar, infrared imaging, visible-light facial recognition, and Bluetooth-integrated metal detection, into a single operator dashboard for concealed weapon detection. Built as an iteration on a prior capstone team's gantry and radar hardware, the project's core challenge was improving the mmWave radar imaging resolution and speed while making disparate subsystems (a Raspberry Pi, a Windows radar workstation, and a BLE-connected ESP32-based metal detector wand) work together as one coherent, real-time system. In my role as Systems Integration Engineer, I was responsible for architecting how the independent subsystems communicated and combined into a unified product. Troubleshooting the system bring-up was a major challenge, as the hardware and software were handed off from the previous team and had to be reverse-engineered and reimplemented before they could be utilized, iterated upon, and integrated with novel functionality. I contributed significantly to every aspect of the system's functionality. While the gantry's mechanical design and radar hardware were largely unchanged from the previous team, I replaced the gantry motors with internal-encoder motors to improve travel consistency, substantially modified the radar imaging software to improve image quality and scan speed, and moved the orchestration between the laptop running mmWave Studio and the Raspberry Pi running motor control from SSH automation to a TCP socket-based communication protocol to reduce uplink timing variability. Additionally, the metal detector wand, infrared camera stream and object detection, facial recognition features, and the user-facing dashboard were all novel additions I took a leading role in designing and implementing.

SmartTin

Accountability tool for nicotine pouch users

SmartTin is a product intent project for a pocket sized application controlled locking container with the ability to detect and count opening events and lock the container based on a user defined schedule. The device is intended to help users of nicotine pouches reduce their consumption by providing accountability and control over access to the product. The intial interation of the device was built around an ESP32C3-Supermini dev board, a 3D printed enclosure and worm gear locking mechanism driven by an N20 gear motor, and a magnetic reed switch to detect opening events. The next iteration in development will swap the ESP32 for nRF52 series microcontroller to reduce power consumption and improve BLE optimization, and will feature a custom PCB to reduce size and improve manufacturability, along with trading the cylindrical form factor for a rectangular form factor to simplify the locking mechanism and reduce the overall size of the device.

FitnessSlot

Exercise randomizer

A device I built for my personal use to randomly display a new excercise from a list each time it is turned on in order to introduce an element of random variability to my fitness habits and break up long work sessions with brief exercise using the pomodoro method. Breadboard device consisting of an ESP32C3-Supermini dev board, LCD display, battery and power switch. The ESP32 runs a simple Arduino IDE program that remembers which excercises have already been displayed on each traversal of the list to reduce repitition and randomly selects a new excercise from the remaining list each time the device is powered on.

Coil Gun

Electromagnetic projectile launcher

A fun little physics demo project I built in college. The coil gun is a simple electromagnetic projectile launcher that uses a coil to accelerate a ferromagnetic projectile down a barrel. It uses 4 9V batteries to charge a bank of 8 4700uF capacitors, before quickly releasing their energy through a coil to induce a magnetic field that propels the projectile. The gun is operated by a 3 position switch which toggles between idle, chargining, and firing states and feaures an LED indicator which lights up when charging begins and gradually dims as the capacitor bank is charged, going dark when the gun is ready to fire. Credit: This project was inspired by the book "15 Dangerously Mad Projects for the Evil Genius" by Simon Monk.
